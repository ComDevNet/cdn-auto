# Config

- [automation.conf](./automation.conf) — generated by `scripts/data/automation/configure.sh` (gitignored). Controls server version, S3 destinations, harvest/dispatch schedule, ModuleGaze, and OC4D assessment sync.
- [oc4d/student-map.example.csv](./oc4d/student-map.example.csv) — template for optional local student overrides (`source_student_name,studentId,parentOrg`)
- [oc4d/assessment-map.example.csv](./oc4d/assessment-map.example.csv) — template for optional local assessment overrides (`source_assessment_name,assessmentId,parentOrg`)
- [oc4d/api-credentials.example](./oc4d/api-credentials.example) — optional API login file (`OC4D_API_IDENTIFIER` / `OC4D_API_PASSWORD`)
- [oc4d/module-map.csv](./oc4d/module-map.csv) — ModuleGaze moduleId → display name fallback
- `oc4d/student-map.csv` / `oc4d/assessment-map.csv` — created locally on configure when missing; gitignored. Prefer cloud auto-map; treat these as overrides.
- `oc4d/database.url` (optional) — Postgres URL for DB-first assessment harvest; gitignored if present

## Ownership & permissions

- `automation.conf` is owned by the service user (typically `pi`) and `chmod 600`
- Local OC4D map files are created from examples on first configure and are not overwritten later
- Prefer the Configure menu over hand-editing live units
